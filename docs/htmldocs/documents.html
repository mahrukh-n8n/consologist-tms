Managing documents

Open Documents to see the active documents in projects you can access. Each row shows the project, version, attachment count and last update.

  • Open shows the document and its attachments.
  • Archive moves the document into the Archived list and keeps its contents. Select Archived → Restore to return it to Active.
  • Delete opens a confirmation for the named document. Enter a reason and select Delete document to permanently remove it and its attachments. Select Cancel to keep it.

Archive, Restore and Delete require permission to modify documents. If an action fails, the notification explains the problem.
